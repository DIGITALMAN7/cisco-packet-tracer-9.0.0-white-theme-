Launches Cisco Packet Tracer with a white interface while preserving the user’s original Windows theme.

Features:

One-click .cmd installer
Creates a Packet Tracer desktop shortcut
Uses the official Packet Tracer icon
Keeps the white interface active while Packet Tracer is running
Restores the original Windows theme after Packet Tracer closes
Blocks inbound and outbound Packet Tracer network access on Private and Public networks
Can be deleted after the first installation run
Note: the current script does not automatically delete itself yet; the installer can be deleted manually after installation.
