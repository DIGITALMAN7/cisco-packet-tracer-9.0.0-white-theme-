# Packet Tracer White Theme Installer

Launches Cisco Packet Tracer with a white interface while preserving the user's Windows theme.

Features:
- One-click `.cmd` installer
- Creates a Packet Tracer desktop shortcut
- Uses the Packet Tracer icon
- Restores the original theme after startup
- Blocks Packet Tracer inbound and outbound network access on Private and Public networks
